# 视频音频提取器

这是一个使用纯 HTML、CSS 和 JavaScript 构建的视频音频提取工具，可以从视频文件中提取音频并以 MP3 格式导出。

## 功能特点

- 从各种格式的视频文件中提取音频
- 使用拖放或文件选择器上传视频
- 内置音频播放器预览提取的音频
- 下载提取的音频为 MP3 格式
- 现代化、简洁的界面设计
- 纯前端实现，所有处理都在浏览器中完成
- 无需服务器，保护用户隐私

## 支持的视频格式

- MP4 (.mp4)
- AVI (.avi)
- MOV (.mov)
- WebM (.webm)
- MKV (.mkv)
- WMV (.wmv)
- 以及其他大多数浏览器支持的视频格式

## 技术实现

该项目使用以下 Web 技术实现：

- **HTML5**: 结构和文件 API
- **CSS3**: 布局和动画
- **JavaScript**: 核心功能实现
- **Web Audio API**: 音频处理
- **Media Capture and Streams API**: 音频提取
- **FileReader API**: 文件操作

## 使用说明

1. 打开 `index.html` 文件
2. 拖放视频文件到指定区域或点击选择文件按钮
3. 等待提取过程完成
4. 使用内置播放器预览提取的音频
5. 点击"下载 MP3"按钮保存音频文件

## 浏览器兼容性

该应用在以下浏览器中测试通过：

- Google Chrome (推荐)
- Mozilla Firefox
- Microsoft Edge
- Opera

## 注意事项

- 视频文件不会上传至任何服务器，所有处理都在本地浏览器中完成
- 大型视频文件处理可能需要较长时间
- 某些特殊格式的视频可能无法正确提取音频，请尝试其他格式
